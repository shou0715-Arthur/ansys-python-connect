Python ↔ Ansys AEDT 連線計畫

目標工具：Icepak / Circuit（AEDT 2025 R2）｜形式：連線測試腳本 MVP｜建立日期：2026-11-02｜專案：projects/ansys-python-connect

1. 目標與範圍

用 Python（PyAEDT）在本機建立與 Ansys Electronics Desktop 2025 R2 的穩定連線，並以 Icepak 與 Circuit 兩個設計完成「開啟 → 建模 → 設定 → 存檔 → 釋放」的 smoke test。此 MVP 是後續電熱雙向耦合（Q3D → Circuit → Icepak 迭代）自動化的地基。

本階段不做：GUI、Web App、實際跑完整模擬（只做到可選的最小 analyze）。

2. 承接 05-27 研討會的決策

研討會決策在本計畫的落實方式
PyAnsys（PyAEDT）為主要自動化方向全部以 ansys.aedt.core 高階 API 撰寫，僅在 API 缺口時回退到 COM / Record Script
兩階段開發：先手寫 MVP 驗證 API，再交給 AI 擴充Phase 1–3 即為手寫 MVP；驗證通過的腳本成為後續 AI 迭代的「參考腳本」

錄製-提示-迭代執行錯誤訊息回饋給 AI 修正，預期 2–3 輪收斂

6. 核心程式碼骨架

以下為 PyAEDT 近期版本（ansys.aedt.core）的參數命名：project、design、version、non_graphical、new_desktop。舊式 projectname / specified_version 已被棄用，看到警告時依此對照。

config.py

from pathlib import Path

AEDT_VERSION = "2025.2"
NG_MODE = False                       # 穩定後改 True
OUTPUT_DIR = Path(__file__).resolve().parents[2] / "output"
OUTPUT_DIR.mkdir(exist_ok=True)

session.py

from contextlib import contextmanager
from ansys.aedt.core import Desktop
from .config import AEDT_VERSION, NG_MODE


@contextmanager
def aedt_session(non_graphical: bool = NG_MODE, new_desktop: bool = True):
    """保證無論成功或例外，AEDT 都會被釋放，避免殘留程序與授權鎖。"""
    desktop = Desktop(
        version=AEDT_VERSION,
        non_graphical=non_graphical,
        new_desktop=new_desktop,
        close_on_exit=True,
    )
    try:
        yield desktop
    finally:
        desktop.release_desktop(close_projects=True, close_desktop=True)

test_icepak.py（Phase 2）

from ansys.aedt.core import Icepak
from aedt_connect.config import AEDT_VERSION, NG_MODE, OUTPUT_DIR

RUN_SOLVE = False   # 要測求解器授權時改 True

ipk = Icepak(
    project=str(OUTPUT_DIR / "connect_test.aedt"),
    design="ipk_smoke",
    version=AEDT_VERSION,
    non_graphical=NG_MODE,
    new_desktop=True,
)
try:
    ipk.modeler.model_units = "mm"
    chip = ipk.modeler.create_box(
        origin=[0, 0, 0], sizes=[10, 10, 2], name="chip", material="silicon"
    )
    ipk.assign_solid_block(object_name="chip", power_assignment="1W")
    setup = ipk.create_setup(name="Setup1")
    print("objects :", ipk.modeler.object_names)
    print("setups  :", [s.name for s in ipk.setups])
    if RUN_SOLVE:
        ipk.analyze(setup="Setup1")
    ipk.save_project()
finally:
    ipk.release_desktop(close_projects=True, close_desktop=True)

test_circuit.py（Phase 3）

from ansys.aedt.core import Circuit
from aedt_connect.config import AEDT_VERSION, NG_MODE, OUTPUT_DIR

RUN_SOLVE = False

cir = Circuit(
    project=str(OUTPUT_DIR / "connect_test.aedt"),
    design="cir_smoke",
    version=AEDT_VERSION,
    non_graphical=NG_MODE,
    new_desktop=True,
)
try:
    sch = cir.modeler.schematic
    p1  = sch.create_interface_port(name="P1", location=[-0.02, 0.0])
    r1  = sch.create_resistor(name="R1", value=50, location=[0.0, 0.0])
    c1  = sch.create_capacitor(name="C1", value=1e-12, location=[0.02, 0.0])
    gnd = sch.create_gnd(location=[0.04, 0.0])
    p1.pins[0].connect_to_component(r1.pins[0])
    r1.pins[1].connect_to_component(c1.pins[0])
    c1.pins[1].connect_to_component(gnd.pins[0])

    setup = cir.create_setup(name="LNA", setup_type="NexximLNA")
    setup.props["SweepDefinition"]["Data"] = "LINC 1GHz 10GHz 101"
    print("components:", list(sch.components.keys()))
    if RUN_SOLVE:
        cir.analyze_setup("LNA")
    cir.save_project()
finally:
    cir.release_desktop(close_projects=True, close_desktop=True)

7. 常見問題與風險

症狀原因處理
找不到 AEDT / 版本錯誤ANSYSEM_ROOT252 未設或 version 字串不符確認環境變數；version 必須是 "2025.2"
gRPC 連線逾時防火牆擋住本機 port，或前次 AEDT 殘留關閉殘留 ansysedt.exe；必要時指定 port=
專案被鎖（.lock）上次未正常釋放建構時加 remove_lock=True；一律用 try/finally 釋放
腳本結束後 AEDT 還在沒呼叫 release_desktop用 session.py 的 context manager
背景模式卡死呼叫 RestoreWindow() 之類 UI 命令non_graphical 下避免任何視窗控制 API（見 ansys-aedt-automation skill）
方法名稱不存在 / DeprecationWarningPyAEDT 改版頻繁以 help(obj.method) 或官方 docs 對照；舊名多半仍可用但會警告
analyze 失敗：授權求解器授權不足smoke test 保持 RUN_SOLVE=False；前處理不佔求解授權
